# Spanish support — proposed specification decisions

These decisions were approved in chat on 2026-10-29 (`src:e86c89718081e601095e`). The [design](DESIGN.md) was approved on 2026-10-29.

1. **Success:** Every valid search checks both languages without a selector, displaying each language's definitions as soon as its own lookup completes. A hit in one language does not stop the other search. Downloaded Spanish works after restart without network; existing English installations and cache remain usable. Spanish results contain Spanish-language definitions with source and license links.
2. **Failure:** Each language independently uses offline, fresh cache, online, then stale cache on online failure. Show successful results even if the other language fails; show a retry for the failed language. If both return not found show no definitions; if neither succeeds and either fails, show unavailable. Installation failure preserves both previously installed dictionaries and supports retry; unknown catalog IDs are rejected. A newer query cancels or ignores results of older queries.
3. **Performance and resources:** Run the two lookups concurrently and publish each outcome independently; a slow source must not delay an available result. Keep the existing 10-second online request timeout and 2 MiB response cap per language, 365-day freshness and existing cache limits (128 memory records and 1,000 disk records). Keep the existing 20-minute download timeout, exact pinned size and checksum validation, and 1 GiB extraction ceiling. No unmeasured startup or lookup latency guarantee is proposed.
4. **Trust boundary:** Queries, web responses and downloaded archives are untrusted. Validate queries, use fixed provider URLs with proper escaping, bound time and size, extract Spanish definitions to plain text rather than render HTML, validate links, and accept only pinned, checksum-verified catalog archives under existing safe extraction rules. Unrecognized Spanish HTML is an unavailable source, not a fabricated or wrong-language definition.
5. **Compatibility and rollout:** Keep English's installed path, cache identities and behavior readable without migration. Install Spanish separately and preserve English on install, recovery or failure. Ship the feature with the app; no flag or data migration. Rolling back to an older app retains English functionality; the older app does not expose Spanish data. Do not publish a new release as part of this design/spec approval.
