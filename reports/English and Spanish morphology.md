# UniMorph offers a practical morphology candidate

**UniMorph is the strongest first candidate to evaluate for both English and Spanish**, because it publishes explicit lemma–inflected-form pairs in comparatively manageable data files. Its datasets declare CC BY-SA 3.0, so a separate, attributed data package is plausible alongside wdict's MIT-licensed code, subject to a review of the exact distribution and derivative-data obligations. This is a feasibility recommendation, not a finding that the data is accurate, complete, or legally cleared for a specific release. Neither candidate has been tested against wdict's installed dictionaries or on the target machine. ([UniMorph English](https://github.com/unimorph/eng), [UniMorph Spanish](https://github.com/unimorph/spa), [Creative Commons license](https://creativecommons.org/licenses/by-sa/3.0/))

## Both languages have structured data to test

UniMorph represents a lemma, an inflected form and morphological features; a reverse index could look up a form and return one or more possible base forms. The English repository declares its source as Wikipedia and its data license as CC BY-SA 3.0; its file page reports **17.2 MB**. Its file was not retrieved for this investigation, so irregular examples, accuracy and actual current coverage remain unverified. ([UniMorph project](https://unimorph.github.io/), [English data file](https://github.com/unimorph/eng/blob/master/eng))

The Spanish repository identifies English Wiktionary as its source and reports **1,196,245 inflectional forms**, drawn from noun, adjective and verb paradigms; GitHub reports its data file as **48 MB**. These are publisher figures, not measured coverage for wdict. A form can have multiple base forms: Wiktextract's Spanish entry for `fui` identifies both `ir` and `ser`; that example does not establish that the UniMorph file contains either mapping. The UI and data model should preserve such ambiguity instead of silently selecting one lemma. ([UniMorph Spanish](https://github.com/unimorph/spa), [Spanish data file](https://github.com/unimorph/spa/blob/master/spa), [Wiktextract example](https://kaikki.org/dictionary/Spanish/meaning/f/fu/fui.html))

## Wiktextract trades a larger pipeline for richer entries

Wiktextract exposes structured forms and form-of relationships, including a documented `datasets` → `dataset` example. It could supply candidates for both languages from a single Wiktionary-derived pipeline, but the raw all-language extraction is listed as **2.9 GB compressed** and 24.8 GB uncompressed. That is not the eventual size of a morphology-only index, which has not been measured. Its extractor's MIT license should not be confused with the rights governing extracted dictionary data. UniMorph is therefore the simpler first experiment; Wiktextract is a useful fallback if measured coverage or provenance makes it preferable. ([Wiktextract paper](https://aclanthology.org/2022.lrec-1.140/), [example entry](https://kaikki.org/dictionary/English/meaning/d/da/datasets.html), [raw downloads](https://kaikki.org/dictionary/rawdata.html), [extractor license](https://github.com/tatuylonen/wiktextract/blob/master/LICENSE))

## Compatibility depends on a specific package and tests

Before adopting a dataset, pin a revision and checksum, examine actual rows and attribution, and review the license terms for the intended derived index and distribution. Keep the data's source, license and transformations identifiable; CC BY-SA's attribution and share-alike conditions must not be treated as an MIT grant. The exact rights and attribution obligations of a particular extracted package remain to be assessed. ([Creative Commons license](https://creativecommons.org/licenses/by-sa/3.0/), [Wikimedia terms](https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use))

Build a small evaluation set covering regular and irregular English and Spanish forms, accents, ambiguous forms and words absent from the dictionaries. Measure candidate accuracy and incremental coverage against the exact installed StarDict snapshots, then measure compressed and installed index sizes, first-use latency, memory and cancellation. Return only candidate lemmas present in the relevant dictionary, while retaining multiple valid matches. If the dataset is unreliable or cannot be distributed appropriately, bounded regular-form rules remain the fallback. None of these measurements has yet been performed.

Morphology mappings do not by themselves correct misspelled phrases. The requested `look foward to` → `look forward to` behavior needs a separate bounded search over phrase headwords actually present in the installed dictionary; its coverage and cost also need measurement.
