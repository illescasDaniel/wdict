The user approved French dictionary lookup and interface, a French voice comparable to the existing voices, and French
morphology alternatives because the existing languages have them. Searches continue to cover all supported languages
without a search-language selector. French pronunciation follows Piper and eSpeak, with no source recording download.
The user found the tested Piper samples for bonjour, bon and bonne acceptable; this does not establish broader quality.
The design, spec and architecture approvals and verification limits are in `sdd/french-support.html`.
