The first agreed v1 scope (2026-10-27) made offline dictionaries, a response cache and both languages "nice to have",
with English online lookup as the required baseline. Inflected forms and spelling suggestions were deferred past v1.

Both the cache and the in-app dictionary download were promoted to required the same day; see
[v1-offline-download-and-cache-required](v1-offline-download-and-cache-required.md).
