# OpenCode did not load the project MCP servers

On 2026-11-13 the OpenCode session started without `agemem`, `codenav-go` or `webnav`: the project's MCP servers are declared in `.mcp.json`, which Claude and Codex read but OpenCode ignores. Impact: the session skipped the required `project_memory_recall` at task start and could not use `codenav-go` for type-checked Go edits until the user asked about it. Reproduction: start OpenCode in a checkout that only has `.mcp.json`; `opencode mcp list` shows no servers and the tool catalog lacks the namespaces. Fix: added `opencode.json` (same three servers, OpenCode V2 shape `mcp.servers.<name>` with `type: "local"`, `command` array, `environment`); the servers connected after the OpenCode server restarted/reloaded. Note: `opencode mcp list` still printed "No MCP servers configured" right after writing the file — the catalog only changed after the server restart, so verify availability via the tool catalog, not one early list call.
