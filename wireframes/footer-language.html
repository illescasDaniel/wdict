Footer and interface language

Design proposal · Review the examples below. Scroll inside the second window to see the footer stay visible.

Review only — proposed behavior

The footer stays at the bottom of the app window on both screens. The content scrolls independently and its final item remains accessible above the footer. Appearance remains available alongside the new interface language selector.

Changing the selector immediately translates app-owned text, labels, statuses, errors and accessibility names across both screens. Dictionary definitions, headwords, source names and license text remain as supplied. Each lookup still searches both English and Spanish dictionaries.

Proposed defaults: English when no valid preference is saved; remember a selected language across restarts. If storage is unavailable, retain the selection for the current session. Native select supports keyboard interaction. The examples use native language names so each option is recognizable.
